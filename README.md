# Surya Teja Mothukuri

Personal portfolio. Data Scientist & AI Engineer, New York City.

A single scroll-driven page: agentic GenAI, production ML, and the data
engineering underneath.

**Built with** vanilla JavaScript, GSAP and ScrollTrigger, Lenis, and a small
Node build step. No framework.

Have a look around.

---

## Running it

```bash
npm run build     # generate the site
npm start         # rebuild on save, serve on http://localhost:8000
```

Nothing to install. Needs Node 18 or newer.

The page is generated: edit `content/` for words and numbers, `src/` for
markup, styling and behaviour, then rebuild. `index.html`, `style.css`,
`script.js` and `assets/facts.js` are build output and each says so at the
top, so any edit to them is lost on the next build.
